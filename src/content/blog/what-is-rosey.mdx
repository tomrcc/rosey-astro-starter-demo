[Rosey](https://rosey.app) is an open-source translation tool that works on any static site's built HTML output — regardless of the framework that generated it. Rather than hooking into your SSG's build process, Rosey operates as a postbuild step on the final HTML files.

## How it works

You mark translatable elements with `data-rosey` attributes directly in your templates:

```html
<h1 data-rosey="hero-title">Welcome to our site</h1>
```

Running `rosey generate` scans the built output and produces `rosey/base.json` — a manifest of every translatable string keyed by its `data-rosey` value. Translations live in locale files like `rosey/locales/fr.json`, where each key maps to an object containing the original text and the translated value.

Running `rosey build` then produces a complete translated copy of the site for each locale, substituting the translated values directly into the HTML.

## Key concepts

- **Framework-agnostic**: Works with Astro, Hugo, Eleventy, Next.js — anything that outputs HTML
- **Namespacing**: Use `data-rosey-ns` and `data-rosey-root` to organize keys hierarchically (e.g. `index:hero:title`)
- **Non-invasive**: Rosey never touches your source files. It reads from the build output and writes translated copies alongside it
