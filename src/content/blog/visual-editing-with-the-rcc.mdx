The Rosey CloudCannon Connector (RCC) is a client-side script that bridges Rosey's translation files with CloudCannon's Visual Editor. It loads only inside the editor and gives content teams a way to edit translations directly on the page — no JSON files, no context-switching.

## The locale switcher

When the RCC initializes, it injects a floating action button into the Visual Editor. Clicking it reveals a popover with every available locale. Selecting one swaps the page content to show translated text, with inline editors on each `data-rosey` element.

Switching back to "Original" restores the source content with all of CloudCannon's normal editing infrastructure intact.

## Stale translation detection

When the original English text changes after a translation was written, the RCC flags that translation as stale. Stale elements get an amber dashed border in the editor, and the locale switcher shows a count badge. Editors can resolve staleness by updating the translation or clicking "Mark as reviewed."

## No editing infrastructure required

The RCC creates its own inline editors on every `data-rosey` element — it does not depend on existing editable regions, Bookshop, or any other CloudCannon editing setup. Sites with zero editing infrastructure still get full visual translation editing.
